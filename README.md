## 🚀 Features

✅ Home screen with **dark and light mode**  
✅ **Search functionality** to quickly find products  
✅ **Add, remove, and update products** 

---

## 🛠️ Tech Stack

### Backend (Spring Boot)
- Spring Boot
- Spring Web
- Lombok
- JPA/Hibernate
- MySQL

### Frontend (React)
- React.js
- Redux Toolkit (for state management)
- Axios (for API calls)
- Tailwind CSS

### Database
- MySQL (via Spring Data JPA)

---




## 🐝 API Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/product/{id}` | GET | Fetch all products |
| `/api/products` | POST | Fetch all products |
| `/api/products/{id}` | PUT | Update product |
| `/api/products/{id}` | DELETE | Delete product |\
| `/api/products/search` | GET | Search product |
